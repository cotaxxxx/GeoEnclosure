# GeoEnclosure 実例の事前計画

2026-11-26 JST · DIAGNOSTIC_ONLY · chat の監査待ち

対象は Judge が指定したマクローリン列の積分条件である。零点の個数、離心率の包囲、そこでの無次元回転率の包囲を確かめる。符号を取る量は $F=af$ とする。$a>0$ なので同じ零点を数える。式、単調性、剰余の証明は [DERIVATION.md](DERIVATION.md)。

## Measure

相似で尺度を消し、積分を $\arcsin$ の閉じた式にする。$\Psi(s)=F(\sqrt s)$ の積分から $\Psi'(s)\ge22/105$ を示す。したがって $F$ は $(0,1)$ で厳密増加する。端点の展開は $(0,1/8]$ と $[63/64,1)$ にそれぞれ固定し、前者の値域を $[-4/15,-1/4]$、後者を $[1/4,3/2]$ で囲う。解析の剰余は $e\downarrow0$ で $0\le R_0\le e^4/(1-e^2)$、$e\uparrow1$ で $-11q^3\le R_1\le(5\pi/2)q^2$（$q=\sqrt{1-e^2}$）。

## Enclose / Read

1. MPFR の下向き・上向き丸めで、$1/8$ と $63/64$ の点の $F$ が負と正であることを確かめる。すべての入力は正確な有理数。試す精度は128、256、512ビットのこの順とし、符号が分離したらその時点の区間を使う。計算核のビルドと K1 の検査は候補Bの方式を踏襲する。
2. 両端が厳密な反符号を持つ区間を保持し、中点の区間を評価する。零を含む場合は下側四分点と上側四分点をこの順で両方評価する。得た負の点のうち最大の座標、正の点のうち最小の座標で区間を狭める。どちらの端も動かない、包囲が非有限、両端が逆転する、160回で目標に届かない場合は未確定として保全する。参考の近似値は初期区間、分割、符号判定の入力に含めない。
3. 移動で除いた区間は導出の第2節の単調性を使い、左端の MPFR 下端と右端の MPFR 上端で箱全体を包む。負側と正側の箱の両端、値域、両方の評価IDを台帳に記録する。解析の端の二箱、除いた箱、最後の根の箱でちょうど $(0,1)$ を覆う。箱は共有端点でだけ重なり、0 と 1 を開端とする。
4. 目標は根の箱の幅 $2^{-52}\le10^{-15}$。両端の反符号と厳密増加により、そこに根が一つある。加えて同じ箱の $F'$ を MPFR の区間で直接評価し、下端が厳密に正であることを検査する。精度は手順1と同じ順。回転率は根の**箱全体**で MPFR により包囲する。

## 独立した読み直し

`verify_certificate.py` は MPFR の計算側を import せず、実行バイナリも呼ばない。根の更新、符号、全箱の端点と被覆を正確な有理数で再構成する。数学の値は別に、192ビットの固定二進格子、2,048項の正係数級数、幾何級数の剰余で包み直す。$F$ は $b_n$ の級数、$F'$ はその微分、回転率は $U(s)=\arcsin(e)/e$ の級数を使う。台帳の厳密符号をこの別式でも読めることを要求し、MPFRと別式の区間の交差も点と根の箱で調べる。

公表用の回転率の区間は二つの保証区間を含む外包を取り、10進16桁の格子に外向きに丸める。離心率の表示にも同じ格子を使うので、表示を広げても幅は $2^{-52}+2/10^{16}<10^{-15}$。計算には小数表示を戻さない。

## 記録と順序

固定入力は `PLAN_INPUTS.json`。記録は `EVALUATIONS.jsonl`（MPFRの端点と精度）、`STEPS.jsonl`（分割と評価ID）、`SIGN_LEDGER.jsonl`（解析・数値の箱と符号）、`RESULT.json`、`INDEPENDENT_CHECK.json`、実行時の `MANIFEST.json` と `RESULT_SHA256SUMS.txt`。MPFR の端点は整数の仮数と二の指数をそのまま保存する。未確定の場合も作成済み台帳と停止理由を保持する。

配置案は `cotaxxxx/GeoEnclosure` の `examples/maclaurin-jacobi-bifurcation/`。計画、導出、コード、固定入力、SHA-256 をまとめて事前登録する。chat の監査、Judge の実行承認、Dig の実行の順。研究PCでの開始条件は **候補B v2の終了確認**と**2026-11-26 18:14 JST以降**の両方である。作業機では人工的な丸めと台帳の検査だけを行う。[実行手順](README.md)
