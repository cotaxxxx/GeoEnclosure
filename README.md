# GeoEnclosure

**Decide What to Measure. Enclose Values. Read Signs.**  
**何を測るか決める。値を包む。符号を読む。**

GeoEnclosure は、問題の**構造**を先に調べ、適切な数式の表示を選び、**保証付き区間包囲**と**符号判定**によって不要な探索領域を除外する研究方法論の名称です。

> **基本方針：計算を増やす前に、計算を減らす方法を考える。**

## 目的

- 対称性、角度、方向、単調性などから、調べるべき量・領域を選ぶ。
- 区間演算によって関数や導関数の値を保証付きで包囲する。
- 正・負・厳密な零・零を含む未判定の状態を区別する。
- 必要な場合のみ領域を細分化し、別の表示や解析的不等式を検討する。
- 結果の**数学的主張**と**計算・監査の到達状態**を別々に記録する。

## 基本操作

| 操作 | 意味 |
| --- | --- |
| **Measure** | 結論に必要な量を決める。対称性・共通項・有効な方向から、どの量の符号が分かれば何が言えるかを選ぶ |
| **Enclose** | 値域を誤差込みの保証付き区間に包む |
| **Read** | 区間の符号から除外・保留・次の検証を判断する |

角度は重要な動機ですが、**すべての適用で角度そのものを計算する必要があるわけではありません**。

例えば `F(x)=x-x+1`, `x∈[-1,1]` は、式をそのまま区間評価すると `[-1,3]` ですが、代数的に整理すれば厳密に `F(x)=1` です。これは、細分化の前に表示を工夫する意味を示す基本例です。

## 数学的な位置づけ

GeoEnclosure は区間演算、適応的細分化、平均値形式、区間 Newton 法などを新しく発明したと主張するものではありません。**既存の精度保証付き数値計算、解析、対称性の利用、領域被覆、独立照合を問題に合わせて設計・組み合わせる方法論**として整理しています。

実際の厳密性は、各問題の定義、包囲演算の丸め保証、積分・級数の誤差界、被覆、境界の扱い、検証記録によって決まります。SHA-256 の一致だけで数学的な正しさは証明されません。

```bash
cd reader/GER2/examples
```
